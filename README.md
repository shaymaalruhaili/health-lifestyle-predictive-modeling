# Health Lifestyle Statistical Analysis

## Overview
This project explores a Health Lifestyle dataset using descriptive and inferential statistical techniques in R. The analysis investigates relationships between demographic, lifestyle, and clinical variables to identify factors associated with blood pressure, heart rate, BMI, sleep duration, and sleep disorders.

## Dataset
- 374 health records
- Demographic, lifestyle, and clinical variables
- Missing categorical values handled using mode imputation

## Project Objectives
- Perform data cleaning and preprocessing
- Generate descriptive statistics
- Visualize data distributions
- Conduct correlation analysis
- Build a multiple linear regression model
- Detect outliers
- Perform probability analysis

## Methods
- Data Cleaning
- Mode Imputation
- Descriptive Statistics
- Histograms
- Boxplots
- Pearson Correlation
- Multiple Linear Regression
- Probability Analysis

## Tools
- R
- dplyr
- ggplot2
- readr

## Key Results
- Age, stress level, and physical activity significantly predict systolic blood pressure.
- Age has the strongest negative correlation with heart rate.
- Sleep duration contains several outliers.
- Weak positive relationships exist between sleep disorders and blood pressure, as well as sleep duration.
